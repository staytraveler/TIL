### 1. 함수의 기본 구조

```javascript
function calculateArea(width, height) { // 1. 함수 이름과 매개변수(parameter)
    console.log('함수 안으로 들어왔습니다.'); // 2. 실행할 로직

    const area = width * height;

    return area; // 3. 반환값 - 호출한 곳으로 값 전달
}

calculateArea(10, 20);
```

함수가 호출될 때마다 매번 새로운 스코프에서 변수가 다시 만들어지고, 그 이후에 값이 바뀔 일이 없으면 `const`가 기본. `let`과 `const`의 사용 특징을 잘 구분하는 습관을 들이면 좋을 듯.

### 2. 매개변수(parameter) vs 인수(argument)

함수를 정의할 때 설정하는 통로를 매개변수, 실제 호출할 때 넘기는 값을 인수라고 한다. 매개변수는 함수가 호출될 때 값을 받기 위해 함수 내부에 만들어지는 **지역 변수**.

```javascript
function greet(name) {
    console.log(name);       // 내부에서는 자유롭게 접근 가능
    console.log(arguments);  // 실제로 들어온 인수들을 보여줌 (일반 함수에서만 사용 가능, 화살표 함수는 불가)
    return `${name}님 안녕하세요!`;
}

console.log(greet('홍길동'));
// console.log(name); → 함수 밖에선 안 됨. ReferenceError: 함수 내부(지역 스코프)에서만 살아있음

// 인수 개수 불일치
console.log(greet());                    // name이 undefined → "undefined님 안녕하세요!"
console.log(greet('홍길동', '이순신'));    // 두 번째 인수는 무시됨
```

**매개변수 기본값**: 인수가 전달되지 않거나 `undefined`가 들어오면 기본값이 쓰임.

```javascript
function hi(name = '아무개') {
    return `${name}안녕?`;
}

console.log(hi());
```

### 3. return 이후 코드는 실행되지 않는다

함수는 `return`으로 값을 반환하면 그 아래 코드는 실행되지 않는다.

### 4. 함수 선언문 vs 함수 표현식

**함수 표현식** (변수에 값으로 담는 방법)

```javascript
const hi = function hiii(name) { // 함수 이름 생략 가능
    return `${name}님 안녕하세요!`;
};
```

**함수 선언문**

```javascript
function hello(name) {
    return `${name} 안녕?`;
}
```

함수 선언문은 **호이스팅**이 발생한다 — 코드 실행 전에 함수 선언문이 먼저 준비되기 때문. 그래서 선언 위치보다 먼저 호출해도 동작해 헷갈릴 수 있어서, 실무에서는 함수 표현식을 더 선호하는 경우가 많다.

### 5. 객체의 프로퍼티 값으로 함수 넣기 (메서드)

```javascript
const myObject = {
    sayHi: function () {
        console.log('반갑습니다');
    }
};

myObject.sayHi(); // 반갑습니다
```

### 6. 콜백 함수와 고차 함수

함수에 콜백 함수(표현식으로 작성한 함수를 값으로 넘겨서)로 동작하게 하는 것도 방법 중 하나.

```javascript
function manager(task) {
    console.log('매니저가 업무를 지시합니다');
    task(); // 넘겨받은 함수를 실행
}

manager(sayHello);
```

콜백 함수는 지금 바로 실행할 함수가 아니라 **필요한 시점에 호출**된다.

**고차함수(Higher-order function)**: 함수를 인수로 받거나, 함수를 반환하는 함수. 그렇지 않은 평범한 함수는 그냥 **일반 함수**라고 부른다

```javascript
function calculator(calculateCallback, a, b) {
    console.log('계산을 시작합니다.');
    // 계산 '시점'은 calculator가 결정하지만,
    // 계산 '방식'은 외부에서 주입받은 콜백 함수가 결정한다.
    const result = calculateCallback(a, b);
    return result;
}
```

### 7. 배열의 고차함수 — sort()

`sort()`는 자바스크립트가 배열에 기본으로 제공하는 **고차함수**. '정렬 기준'을 담은 콜백 함수를 인자로 전달해서 원하는 순서로 정렬할 수 있다.

```javascript
numbers.sort(function (a, b) {
    // a - b가 음수면 a가 앞으로, 양수면 b가 앞으로 정렬
    return a - b; // 오름차순 정렬
});
```

### 8. 스코프(Scope) — 변수를 사용할 수 있는 범위

바깥에서 안쪽 스코프의 변수에는 접근 불가.

```javascript
const message = '바깥';

function showMessage() {
    const message = '안쪽';
    console.log(message);
}

showMessage();       // 안쪽
console.log(message); // 바깥
```

안쪽에서는 바깥쪽 변수를 사용 가능.

```javascript
const label = '바깥';

function printLabel() {
    console.log(label); // "정의된 위치"의 바깥 이름을 찾는다 — 렉시컬 스코프(정적 스코프)
    // "함수가 어디서 호출됐는지"가 아니라, "함수가 어디서 선언됐는지"를 기준으로 찾는다
}

function run() {
    const label = 'run 안쪽';
    printLabel();       // 바깥
    console.log(label); // run 안쪽
}

run();
```

### 9. var / let / const 비교

| 구분 | `var` | `let` | `const` |
|---|---|---|---|
| 스코프 | 함수 스코프 (블록 무시, 함수는 못 벗어남) | 블록 스코프 | 블록 스코프 |
| 재선언 | 가능 | 불가능 | 불가능 |
| 재할당 | 가능 | 가능 | 불가능 (단, 객체/배열 안의 값 변경은 가능) |
| 선언 전 접근 | `undefined` (에러 없음) | `ReferenceError` (TDZ) | `ReferenceError` (TDZ) |

```javascript
// const 객체는 "재할당"만 막힌다 — 내부 프로퍼티 값 변경은 가능
const student = { name: '판다', age: 5 };
student.name = '코알라'; // ✅ 가능
console.log(student.name); // 코알라
```
