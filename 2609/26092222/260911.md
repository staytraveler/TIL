## 1. Date 객체
- `new Date()`로 생성 시점의 날짜/시간을 담은 객체 생성
- `toLocaleString('ko-KR', { timeZone: 'Asia/Seoul' })`로 한국 시간 형식 문자열 변환
- `getFullYear()`, `getMonth() + 1`(0부터 시작하므로 +1 필요), `getDate()`로 연/월/일 개별 추출

```js
const now = new Date();
console.log(now.toLocaleString('ko-KR', { timeZone: 'Asia/Seoul' }));

const year = now.getFullYear();
const month = now.getMonth() + 1;
const date = now.getDate();
```

## 2. this와 화살표 함수
- 일반 함수의 `this`는 **호출 방식**에 따라 결정됨
- 화살표 함수는 **자신만의 `this`가 없고**, 바깥(상위) 스코프의 `this`를 그대로 사용함
- 그래서 객체 메서드 내부의 콜백(`forEach` 등)에서 `this.속성`을 쓰고 싶을 때 화살표 함수가 유리함

```js
const theater = {
  store: '청량리역점',
  titles: ['오딧세이', '옵세션'],
  showMovieList: function () {
    this.titles.forEach(title => {
      console.log(this.store + ':' + title); // 화살표 함수라 바깥의 this(=theater) 사용
    });
  }
};
theater.showMovieList();
```

## 3. for...of와 이터러블
- 이터러블: 값을 순서대로 하나씩 꺼낼 수 있는 값 (배열, 문자열 등)
- 일반 객체(`{}`)는 이터러블이 아니므로 `for...of` 사용 시 `TypeError` 발생

```js
const fruits = ['🍎', '🍌', '🍓'];

for (const fruit of fruits) {
  console.log('for...of:', fruit);
}

const message = '안녕';
for (const character of message) {
  console.log('글자', character); // 문자열도 이터러블
}
```

## 4. Spread 문법 & Rest 파라미터
| 구분 | 위치 | 역할 |
|---|---|---|
| Spread(`...`) | 인수 자리, 배열/객체 리터럴 안 | 값을 **펼쳐서** 개별 값으로 만듦 |
| Rest(`...`) | 함수의 매개변수 자리 | 여러 인수를 하나의 **배열로 묶음** |

```js
// Spread - 배열을 개별 인수로 펼침
const scores = [80, 95, 70];
console.log(Math.max(...scores)); // 95

// Spread - 배열/객체 복사 및 병합 (얕은 복사)
const languages = [...['HTML', 'CSS'], 'JavaScript'];
const updatedStudent = { ...{ name: '홍길동', score: 80 }, score: 90 };

// Rest - 나머지 인수를 배열로 수집
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}
sum(10, 20, 30); // 60
```
> 얕은 복사 주의: 배열/객체를 펼쳐서 복사해도 내부에 중첩된 객체까지 새로 복사되지는 않음 (참조 공유).

## 5. 구조 분해 할당 (Destructuring)
- 배열이나 객체의 값을 개별 변수에 바로 담는 문법

```js
// 배열 구조 분해 - 순서대로 할당
const [primary, secondary] = ['빨강', '파랑'];
const [first, ...rest] = ['유관순', '장보고', '이순신']; // rest에 나머지 배열
const [leader, assistant = '미정'] = ['홍길동']; // 기본값 지정

// 객체 구조 분해 - 키 이름으로 할당 (순서 무관)
const { name, age } = { name: '홍길동', age: 20, major: '역사' };

// 이름 바꿔 담기 + 기본값
const { name: learnerName, job = '학생' } = { name: '홍길동' };

// 함수 매개변수에서 바로 구조 분해 (중첩 객체도 가능)
function printProduct({ name, price, spec: { cpu }, producer = '삼성' }) {
  console.log(name, price, cpu, producer);
}
```

## 오늘의 핵심 정리
- 화살표 함수는 `this`를 새로 만들지 않고 바깥 스코프를 그대로 참조한다.
- `for...of`는 이터러블 전용이며, 일반 객체에는 사용할 수 없다.
- Spread는 "펼치기", Rest는 "모으기" — 위치(호출부 vs 매개변수)로 구분한다.
- 구조 분해 할당으로 배열/객체 값을 변수에 바로 추출하고, 함수 매개변수에서도 활용할 수 있다.
