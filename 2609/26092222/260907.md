### 1. 동등 비교 vs 일치 비교

```javascript
/**
 * 동등 비교(==, !=): 암묵적 타입 변환을 거쳐 타입을 일치시킨 후 비교
 * 일치 비교(===, !==): 타입과 값이 모두 일치하는지 비교 (변환 없음)
 */
```

### 2. 논리 연산자 (&&, ||, !)와 단축 평가

논리 연산자는 **단축 평가(short-circuit evaluation)** 를 한다. 즉 조건에 따라 뒤쪽 값을 아예 평가하지 않고 넘어갈 수 있다.

- `||` : 앞이 truthy면 뒤는 확인하지 않고 앞 값을 그대로 반환
- `&&` : 앞이 truthy면 뒤 값까지 확인해서, 뒤 값을 반환 (즉 "마지막으로 평가된 값"이 반환된다고 이해하면 됨)

```javascript
console.log('apple' || 'banana'); // 'apple' → 앞이 이미 truthy라 뒤는 평가 안 함
console.log(false || 'banana');   // 'banana' → 앞이 falsy라 뒤 값 반환

console.log('apple' && 'banana'); // 'banana' → 앞이 truthy라 뒤까지 평가, 뒤 값 반환
console.log(false && 'apple');    // false → 앞이 falsy라 바로 반환, 뒤는 평가 안 함
```

### 3. 삼항 연산자

조건식에 따라 두 값 중 하나를 선택하는 연산자.

```javascript
조건 ? 값1 : 값2   // 조건이 참이면 값1, 거짓이면 값2
```

### 4. 조건문

- `if`, `else`, `else if`
- `switch` : 각 `case`는 `break`로 빠져나와야 하고, 어디에도 해당 안 될 때를 위한 `default`가 있음

**if문 vs switch문, 언제 뭘 쓰는 게 좋은가**

| 상황 | 추천 |
|---|---|
| 비교 조건이 범위(`>`, `<`), 복합 조건(`&&`, `\|\|`) 등 다양할 때 | `if / else if` |
| 하나의 변수 값이 정해진 여러 값 중 무엇과 "정확히 일치"하는지만 비교할 때 (예: 요일, 상태값, 메뉴 선택) | `switch` |
| 분기가 2~3개 이하로 단순할 때 | `if` (switch는 오히려 코드가 길어짐) |
| 분기가 많고(4~5개 이상), 각 case마다 실행할 코드가 명확히 구분될 때 | `switch`가 가독성 面에서 더 나음 |

즉, **"하나의 값과 여러 후보를 딱딱 비교"** 하는 경우엔 switch가 깔끔하고, **"조건 자체가 복잡하거나 범위 비교가 필요한 경우"** 는 if를 쓰는 게 자연스럽다.

### 7. while문 / do...while문

```javascript
// while문: 조건이 참인 동안 반복
let i = 0;
while (i < 3) {
  console.log(i);
  i++;
}
// 0, 1, 2

// do...while문: 일단 한 번 실행하고 나서 조건을 검사
let k = 10;
do {
  console.log(k); // 10 ← 조건(k < 3)이 처음부터 거짓인데도 한 번은 실행됨
} while (k < 3);
```

**핵심 차이**: `while`은 조건부터 검사하고 들어가지만, `do...while`은 일단 한 번 실행한 뒤에 조건을 검사한다. 그래서 조건이 처음부터 거짓이어도 `do...while`은 최소 1번은 실행된다.

### 8. continue / break

```javascript
for (let i = 0; i < 5; i++) {
  if (i === 2) continue; // 2만 건너뛰고 다음 반복으로
  if (i === 4) break;    // 4에서 반복문 자체를 종료
  console.log(i);
}
// 0, 1, 3
```

- `continue`: 현재 반복의 나머지 코드를 건너뛰고, 다음 반복으로 넘어간다
- `break`: 반복문 자체를 완전히 종료한다

**중첩 반복문에서는 가장 가까운 반복문 하나에만 영향을 준다.**

```javascript
for (let i = 0; i < 2; i++) {
  for (let j = 0; j < 2; j++) {
    if (j === 1) break; // 안쪽 for문만 멈추고, 바깥 for문은 계속 돔
    console.log(i, j);
  }
}
```

### 9. 객체(Object)

```javascript
const dog = { name: '판다', age: 5 };
```

키와 값 쌍으로 구성되어 있고, 이걸 **프로퍼티**라고 한다.

**메서드**: 프로퍼티(상태 데이터)를 참조하고 조작할 수 있는 동작

```javascript
const dog = {
  name: '판다',
  age: 5,
  getInfo: function () {
    return `${this.name}은 ${this.age}세 입니다.`;
  }
};
```

**메서드에서 `this` 사용 시 function vs 화살표 함수**

화살표 함수는 자기만의 `this`를 만들지 않고, **자신이 선언된 위치(스코프)의 `this`를 그대로 물려받는다.** 객체 리터럴 `{ }`은 새로운 스코프를 만들지 않기 때문에, 객체 안에서 화살표 함수를 쓰면 `this`가 그 객체가 아니라 더 바깥(모듈 최상위 등)을 가리키게 된다. 반면 `function` 키워드로 만든 함수는 **누가 호출했는지(`dog.getInfo()`)에 따라 그때그때 `this`가 정해지므로**, 객체의 메서드에서 `this.속성`을 쓰려면 `function`을 써야 한다.

### 10. 프로퍼티 접근 방법

1. 마침표 표기법: `dog.name`
2. 대괄호 표기법: `dog['name']` — 프로퍼티 키를 문자열로 적는다

```javascript
console.log(dog.name);    // '판다'
console.log(dog['name']); // '판다' (동일)
```

**대괄호 표기법의 가장 큰 장점**: 프로퍼티 키 자리에 **변수**를 사용할 수 있다는 것.

```javascript
const key = 'name';
console.log(dog.key);   // ❌ undefined (dog 안에서 진짜 'key'라는 이름을 찾으려 함)
console.log(dog[key]);  // ✅ '판다' (변수 key에 담긴 값 'name'으로 접근)
```

마침표 표기법의 네이밍 규칙(공백·특수문자·숫자 시작 불가)에 안 맞는 키를 쓸 때도 대괄호 표기법이 유용하다.

```javascript
const person = { 'first name': '김용현' };
person['first name']; // ✅ 가능
```

### 11. const로 만든 객체 — 재할당 vs 프로퍼티 변경

```javascript
const dog = { name: '판다' };

dog = { name: '초코' }; // ❌ TypeError: Assignment to constant variable.
                        //    변수(dog) 자체를 다른 값으로 바꾸는 건 불가능

dog.name = '초코';      // ✅ 정상 동작
                        //    변수가 가리키는 객체는 그대로 두고,
                        //    그 객체 "안의" 프로퍼티만 바꾸는 것이라 가능
```

**let이었다면 변수 자체 재할당도 가능:**
```javascript
let cat = { name: '나비' };
cat = { name: '까망' }; // ✅ let은 변수 자체를 다른 객체로 바꿀 수 있음
```

**핵심**: `const`가 막는 건 "변수가 가리키는 대상 자체를 통째로 바꾸는 것"이지, "그 대상 안의 내용물을 바꾸는 것"까지 막는 게 아니다.

### 12. 프로퍼티 추가 / 변경 / 삭제

```javascript
const dog = { name: '판다', age: 5 };

dog.color = '흰색'; // 추가
dog.age = 6;        // 변경
delete dog.age;      // 삭제 (delete 연산자, 키를 지정해서 삭제)

console.log(dog); // { name: '판다', color: '흰색' }
```

### 13. 프로퍼티 존재 확인 — in 연산자

```javascript
console.log('name' in dog);  // true
console.log('age' in dog);   // false (13번 예시에서 삭제했으므로)
```
결과는 `boolean`(true/false) 값으로 반환된다.

### 14. 객체 순회 — for...in

객체의 프로퍼티 키를 하나씩 꺼내는 반복문.

```javascript
for (const key in dog) {
  console.log(`키: ${key}`);
  console.log(`값: ${dog[key]}`);
}
```

여기서 `dog[key]`처럼 **대괄호 표기법**을 쓰는 이유: `key`는 반복마다 `'name'`, `'color'`처럼 값이 계속 바뀌는 **변수**이기 때문에 (10번에서 배운 것처럼) `dog.key`가 아니라 `dog[key]`로 접근해야 한다.
