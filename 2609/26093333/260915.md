## 이벤트 핸들러 등록 및 제거

이벤트 핸들러를 등록하는 방법은 세 가지가 있고, 발전 순서대로 단점이 개선된다.

1. **어트리뷰트 방식 (구식)**: `<button onclick="...">` — HTML과 JS가 섞여 유지보수가 어렵다.
2. **프로퍼티 방식 (과도기)**: `element.onclick = fn` — HTML/JS는 분리되지만, 프로퍼티 하나에 함수 하나만 저장 가능해서 나중에 대입한 함수가 이전 함수를 덮어쓴다.
3. **`addEventListener` (표준)**: 하나의 이벤트에 여러 핸들러를 등록할 수 있는 현대적인 방식.

```js
const $btn3 = document.getElementById('btn3');
$btn3.addEventListener('click', () => console.log('첫번째 임무수행!'));
$btn3.addEventListener('click', () => alert('두 번째 임무 수행'));
```

이벤트 핸들러를 제거하려면 `removeEventListener`에 **등록할 때와 동일한 함수 참조**를 넘겨야 한다. 익명 함수로 등록하면 참조가 달라 제거할 수 없으므로, 제거 대상 함수는 변수에 담아둔다.

```js
const mission = () => alert('특수 임무 수행 완료');

$btn4.addEventListener('click', mission);
$btn4.removeEventListener('click', mission); // 동일 참조여야 제거됨
```

## 이벤트 객체와 this

이벤트가 발생하면 브라우저는 이벤트 정보를 담은 **이벤트 객체**를 만들어 핸들러의 첫 번째 인자로 넘긴다.

```js
document.addEventListener('click', (e) => {
  console.log(`x:${e.clientX}, y:${e.clientY}`);
  console.log(e.target); // 실제 클릭된 요소
});
```

핸들러 내부의 `this`는 함수 종류에 따라 다르게 동작해 혼란을 준다.

- 일반 `function`: `this`는 이벤트가 등록된 요소 (`this === e.currentTarget`)
- 화살표 함수: `this`는 바깥 스코프의 `this`를 그대로 참조 (요소를 가리키지 않음)

```js
$btn.addEventListener('click', function (e) {
  console.log(this === e.currentTarget); // true
});

$btn.addEventListener('mouseover', (e) => {
  console.log(e.currentTarget); // 요소는 이걸로 얻어야 함
});
```

**결론**: 함수 종류와 무관하게 항상 이벤트가 부착된 요소를 가리키는 `e.currentTarget`을 쓰는 것이 `this`보다 안전하다.

## 이벤트 전파(버블링)와 위임

하위 요소에서 발생한 이벤트는 부모 요소로 전파(버블링)된다. `e.target`은 이벤트가 실제로 시작된 요소, `e.currentTarget`은 핸들러가 등록된 요소로 서로 다르다.

이를 활용하면 자식 요소마다 핸들러를 달 필요 없이 **부모에 하나만 등록**해서 처리할 수 있다 (이벤트 위임). `closest()`로 클릭된 지점에서 가장 가까운 대상 요소를 찾는다.

```js
$drinkList.addEventListener('click', (e) => {
  const $item = e.target.closest('li'); // 못 찾으면 null
  if (!$item) return;
  if (!$drinkList.contains($item)) return; // 안전장치

  $item.classList.toggle('highlight');
});
```

동적으로 나중에 추가된 자식 요소(`appendChild`)에도 부모에 위임된 핸들러가 자동으로 동작한다는 것이 이벤트 위임의 핵심 이점.

## 이벤트 제어: preventDefault / stopPropagation

- **`preventDefault()`**: 브라우저의 기본 동작(폼 제출 시 새로고침, 우클릭 메뉴 등)을 막는다. 폼에서는 유효성 검사를 먼저 수행하기 위해 사용.
- **`stopPropagation()`**: 이벤트가 부모로 전파(버블링)되는 것을 막는다. 모달의 내용 영역 클릭이 배경 클릭으로 이어지지 않게 할 때 사용.

```js
$loginForm.addEventListener('submit', (e) => {
  e.preventDefault(); // 새로고침 방지 후 검증
  if ($usernameInput.value.trim() === '') {
    $errorMessage.textContent = '아이디를 입력해주세요';
  }
});

$modalContent.addEventListener('click', (e) => {
  e.stopPropagation(); // 부모(배경)로 전파 차단
});
$modalBg.addEventListener('click', () => {
  $modalBg.style.display = 'none';
});
```

## 마우스 / 키보드 이벤트

- 마우스: `click`, `mousedown`(누를 때), `mouseup`(뗄 때), `mousemove` 등
- 키보드: `keydown`(누르는 동안 계속), `keyup`(뗄 때), `input`(입력값이 최종 반영된 시점)
  - `e.key`: 입력된 문자 (`'a'`, `'Enter'`)
  - `e.code`: 물리적 키 코드 (`'KeyA'`, `'Enter'`)

```js
$keyboardInput.addEventListener('keydown', (e) => {
  if (e.key === 'Enter') {
    // 검색 실행 등
  }
});

// 최신 입력값을 반영해서 처리해야 한다면 input이 더 적합
$keyboardInput.addEventListener('input', (e) => {
  console.log(e.currentTarget.value);
});
```

## 폼 이벤트

`document.forms.폼name`으로 폼을, 그 안의 `name` 속성으로 입력 요소를 바로 가져올 수 있다.

```js
const $form = document.forms.joinForm;
const $username = $form.username;
const $hobbies = $form.hobby; // 체크박스 그룹 (RadioNodeList)
```

- `focus` / `blur`: 입력창에 포커스가 들어오고 나갈 때 (스타일 처리 등)
- `input`: 값이 바뀔 때마다 실시간 반영 (글자 수 카운터 등)
- `submit`: 제출 시 유효성 검사. 조건에 안 맞으면 `preventDefault()`로 제출을 막는다.

```js
$form.addEventListener('submit', (e) => {
  e.preventDefault();

  if ($username.value.trim().length < 2) {
    $error.textContent = '이름은 2글자 이상 입력해주세요';
    return;
  }

  const checkedCount = Array.from($hobbies).filter((h) => h.checked).length;
  if (checkedCount < 2) {
    $error.textContent = '관심사는 2개 이상 선택해주세요';
    return;
  }

  // 검증 통과 → 서버 제출 로직
});
```

## 어트리뷰트(Attribute)와 프로퍼티(Property)

같은 이름을 가리키는 것처럼 보여도 둘은 다르게 동작할 수 있다.

```js
$input.getAttribute('value');       // 읽기
$input.setAttribute('value', 'v');  // 쓰기
$input.hasAttribute('class');       // 존재 확인
$input.removeAttribute('value');    // 삭제
```

- `input.value` **어트리뷰트**: HTML에 적힌 초기값, 이후에도 변하지 않음
- `input.value` **프로퍼티**: 사용자가 입력 중인 현재 값, 실시간 반영
- 체크박스는 타입도 다르다: 어트리뷰트는 문자열(`''`), 프로퍼티(`.checked`)는 boolean

```js
$checkbox.setAttribute('checked', '');
console.log($checkbox.getAttribute('checked')); // '' (문자열)
console.log($checkbox.checked);                 // true (boolean)
```

### data 어트리뷰트와 dataset

화면 동작에 필요한 커스텀 데이터는 `data-이름` 어트리뷰트에 담고, JS에서는 `.dataset.이름`(camelCase)으로 접근한다. 단, DOM에서 그대로 노출되므로 보안이 필요한 데이터에는 쓰지 않는다.

```html
<li data-product-id="p-001" data-price="15000">상품 A</li>
```

```js
$productList.addEventListener('click', (e) => {
  const $item = e.target.closest('.product-item');
  if (!$item) return;

  const { productId, price } = $item.dataset;
  $infoPanel.innerHTML = `
    선택된 상품 ID: <span>${productId}</span><br>
    선택된 상품 가격: <span>${Number(price).toLocaleString()}원</span>`;
});
```

이벤트 위임(`closest`)과 `dataset`을 함께 쓰면, 목록형 UI(상품 목록, 게시판 등)에서 항목마다 핸들러를 달지 않고도 클릭된 항목의 데이터를 바로 꺼내 쓸 수 있다 — 오늘 배운 개념들이 실무에서 어떻게 결합되는지 보여주는 예제였다.
