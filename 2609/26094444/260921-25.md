## React

- `useState` → 상태 관리 및 변경 시 리렌더링
- `useEffect` → 렌더링 이후 Side Effect 처리
- `useMemo` → 계산 결과 메모이제이션
- `useCallback` → 함수 메모이제이션
- `useRef` → 리렌더링 없이 값 유지 및 DOM 참조
- Custom Hook → 재사용할 로직을 Hook으로 분리

## JavaScript 비동기

- 동기 → 작업이 순차적으로 실행
- 비동기 → 작업 완료를 기다리지 않고 다음 코드 실행
- Callback → 비동기 작업 완료 후 실행할 함수 전달
- Promise → 비동기 작업의 결과를 표현
- `.then()` → 성공 처리
- `.catch()` → 오류 처리
- `.finally()` → 성공/실패와 관계없이 실행

## Next.js Router

- `useRouter` → 코드에서 페이지 이동 및 라우팅 제어
- `useParams` → 동적 URL의 파라미터 가져오기
- `useSearchParams` → URL의 Query String 가져오기
- App Router의 `[id]` → URL에 따라 동적으로 페이지 생성

## Zustand

- 전역 상태를 간단하게 관리하는 상태 관리 라이브러리
- Store에서 상태와 변경 함수를 관리
- 컴포넌트 간 props 전달 없이 필요한 상태를 직접 사용
- `persist`를 사용하면 상태를 `localStorage` 등에 저장 가능

## TanStack Query

- 서버 상태를 가져오고 캐싱하는 라이브러리
- `useQuery` → 데이터 조회
- `useMutation` → 데이터 생성/수정/삭제
- Query Cache → 가져온 데이터를 캐싱하여 불필요한 요청 감소
- 서버 상태와 클라이언트 상태를 분리해서 관리

## 핵심 정리

**React State → Zustand → TanStack Query**

- 화면의 로컬 상태 → `useState`
- 여러 컴포넌트가 공유하는 상태 → `Zustand`
- 서버에서 가져오는 데이터 → `TanStack Query`

**React Hook과 비동기 처리, Router, 상태 관리, 서버 상태 관리의 역할을 구분해서 이해했다.**
