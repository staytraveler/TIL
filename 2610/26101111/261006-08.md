# 10/06 Java TIL

## Java 네이밍 관례

| 용도 | Java 관례 | 예시 |
|---|---|---|
| 변수 | camelCase | `maxAge` |
| 메서드 | camelCase | `getUserName()` |
| 클래스 | PascalCase | `UserProfile` |
| 상수 | UPPER_SNAKE_CASE | `MAX_AGE` |
| 패키지 | 소문자 | `com.example.chess` |

## 오늘 배운 내용

- **static 메서드**: 객체 생성 없이 `클래스명.메서드()`로 호출 가능
- **일반 메서드**: 객체 생성 후 `객체명.메서드()`로 호출
- **import**: 다른 패키지의 클래스를 사용할 때 `import`하여 사용
- **void**: 메서드가 값을 반환하지 않을 때 사용
- **문자열 비교**: `==` 대신 `.equals()`를 사용해 내용 비교
